# Editions

This page tells you what these docs cover, so you know which behaviour you can expect from the open source server.

These docs describe the open source vCon Server and nothing else.

A commercial edition also exists. It is built on the published open source image and adds active consent management. It is a separate product with separate documentation.

The open source server carries `lawful_basis` attachments through the pipeline. It does not create, validate, enforce or manage consent. That is by design, and running it does not make a deployment compliant with any law. [Lawful basis](lawful-basis.md) gives the detail.
