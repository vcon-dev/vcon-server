## Limits apply to this drawing

- `to_legacy` loops dialog, analysis, then attachments. The diagram groups the steps by what they do, so the boxes are not a strict call order.
- A non-dict input returns as it came (`common/lib/vcon_egress_compat.py:125-126`). This is not drawn.
- `_body_to_legacy` leaves an invalid JSON string, or a scalar body, on `encoding: "json"` (`common/lib/vcon_egress_compat.py:88-95`).
- `settings.py` does not validate the value at start-up, so a bad version fails on the first egress.
