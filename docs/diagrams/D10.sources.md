## The never created claim rests on these searches

- `lawful_basis` appears in non-test Python only in `common/lib/vcon_compat.py`, `common/lib/vcon_egress_compat.py` and `common/storage/utopia/__init__.py`. The first two mention it in comments, and the adapter only reads it.
- `add_attachment` has no caller outside tests. `add_party` and `add_dialog` have none either, so parties and dialogs arrive from the producer.
- `build_new` has no caller outside tests.
- Diet is the only link that assigns to `attachments`. The filter reads `mime_type`, a key that `normalize_legacy_fields` does not touch.

## Limits apply to this drawing

- `add_attachment` writes `type` and `add_tag` writes no `party`, `dialog` or `start` (`common/vcon.py:129`, `common/vcon.py:200-204`). `_enforce_spec_on_write` renames `type` to `purpose` but does not add those three fields.
- `add_tag` writes a stringified body (`common/vcon.py:145`). `_normalize_json_body_encoding` leaves a string body alone (`common/lib/vcon_redis.py:50-58`), so tags stay in the older shape.
- `require_analysis_grant` defaults to false and exists only in the `utopia` adapter. It reads a basis and skips one upload. It manages nothing.
