## Notes cover what the picture leaves out

- BLPOP scans lists in order, and that order follows chain order in the config (`conserver/main.py:866`, `common/lib/queue.py:86`). Earlier lists win when several hold items.
- A popped id has no in-flight record. A worker that dies mid-chain loses that queue entry, and the main process only restarts the worker (`conserver/main.py:1015`).
- `imports` load once at worker start (`conserver/main.py:821`), while chains reload on every pass (`conserver/main.py:862`).
- Shutdown: the main process sends SIGTERM to live workers (`conserver/main.py:98`), then waits 30 s per worker before `terminate` (`conserver/main.py:1038`, `conserver/main.py:1041`). Thread pools drain first (`conserver/main.py:920`).
- The `tag_router` link can RPUSH to any named list (`conserver/links/tag_router/__init__.py:88`). D05 shows that edge.
- Trace context rides in `context:<list>:<uuid>` beside the queue (`common/lib/context_utils.py:32`). Producers write it first and `_handle_vcon` reads it (`conserver/main.py:713`). `/dlq/reprocess` writes none.
- Followers run in the main process only, and the first poll runs inline at startup (`conserver/follower.py:54`).
