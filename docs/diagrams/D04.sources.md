## Notes

A list with no chain behind it is never read: workers only watch lists named in a chain's `ingress_lists`, `conserver/main.py:679`. The API does not check this on push.

The follower pop is destructive on the upstream side. A vCon that then returns 404 is logged and dropped, `conserver/follower.py:43`.

`conserver/main.py:898` returns a popped vCon to the head of its list on shutdown. That belongs to the worker topology and is drawn in D06.
