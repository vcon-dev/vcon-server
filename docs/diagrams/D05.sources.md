## Notes cover the unusual paths

- Egress runs before storage (`conserver/main.py:352` then `conserver/main.py:368`). A downstream chain can start before the save ends.
- A failed save goes to the storage DLQ and does not fail the chain (`conserver/main.py:425`).
- `links: []` skips the loop and goes straight to `_wrap_up`. A chain with no `links` key raises `KeyError` at `conserver/main.py:255` and lands on the ingress DLQ.
- No `egress_lists` or no `storages` skips that step (`conserver/main.py:353`, `conserver/main.py:369`).
- A halted chain still counts in `conserver.main_loop.count_vcons_processed` (`conserver/main.py:288`).
- A chain `timeout` is only logged (`conserver/main.py:732`) and `enabled` is never read by the worker (`conserver/main.py:679`), so the diagram shows neither.
- Two chains that share an ingress list collapse to the later chain (`conserver/main.py:683`).
