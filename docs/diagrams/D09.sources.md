## Limits apply to this drawing

- The HTTP 500 branch is not drawn. A Redis error during replay returns it and still releases the lock (`api/api.py:1242-1246`).
- A crash leaves the lock in place because it has no expiry (`api/api.py:1219-1221`).
- Replay is at-least-once, so a backend can see the same UUID twice (`api/api.py:1227-1229`).
- `get_vcon` falls back to the configured storages on a Redis miss, so steps 4 and 26 can succeed after the body expires (`common/lib/vcon_redis.py:214-222`).
- The diagram shows adapters that raise. Two adapters differ: `spaceandtime` catches and logs (`common/storage/spaceandtime/__init__.py:70-71`), and `scitt` returns when the vCon is missing (`common/storage/scitt/__init__.py:37-39`). Both count as a success here.
